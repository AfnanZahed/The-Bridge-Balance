# The Bridge Balance

> Learn to lead AI coding agents with engineering judgment. 4 stages. 2 Harvard certificates. 100% free.

## What this is

The Bridge Balance is a student-oriented learning platform that teaches **spec-driven AI agent engineering** through a four-stage curriculum and pairs the coursework with a catalog of paid digital products — Claude Code sub-agents, agent skills, MCP servers, and plugins — that working developers can use directly in their own projects.

## The four stages

1. **Spec-Aware Vibe Engineering Foundations** — lead AI agents with engineering judgment.
2. **Credible Validation** — CS50P + CS50W, two Harvard certificates as international proof.
3. **Mastering AI Coding Agents** — Claude Code, skills, MCP, prompt/context/loop engineering.
4. **Engineering Autonomous AI Agents** — RAG, tool calling, multi-agent systems, evaluations.

## Conventions

- Code blocks are runnable unless labelled `# pseudo`.
- Lectures are numbered `NN-topic` within their stage.
- Each chapter ends with a **Check your understanding** section.
