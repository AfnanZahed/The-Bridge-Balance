# Stage 1 — Spec-Aware Vibe Engineering Foundations

This stage teaches the foundational engineering vocabulary you need to direct an AI agent confidently. The agent can write the code — your job is to know **what** to ask for, **why**, and **how to know it's done right**.

## Chapters

| # | Chapter | Topic |
|---|---|---|
| 1 | [Foundations](./foundations) | Software architecture: system structure, planning, architecture before code |
| 2 | [Core Programming](./core-programming) | Python, JavaScript, variables, conditionals, loops, functions, file handling, error handling |
| 3 | [Frontend](./frontend) | Next.js, page structure, layouts, responsiveness, components, ShadCN / Material UI / DaisyUI |
| 4 | [Backend](./backend) | APIs, HTTP, REST, validation, middleware, logging |
| 5 | [Databases](./databases) | SQL vs NoSQL, PostgreSQL, MongoDB, Redis, graph databases |
| 6 | [Git & GitHub](./git-github) | Commits, branches, pull requests, repos, collaboration |

## Learning outcomes

By the end of Stage 1 you will be able to:

1. Sketch a system's architecture on a whiteboard before asking an agent to build it.
2. Read code in Python or JavaScript and identify the constructs being used.
3. Describe what a frontend component, a backend endpoint, and a database table each do — and which one a problem belongs to.
4. Use Git and pull requests to keep your work traceable and reviewable.

## How this stage is taught

Each chapter pairs a **video lecture** (the primary medium) with this **text companion** (the second medium, for reference and search). Lecture content is delivered separately and pasted into the chapter files here.

> The text is the documentation; the video is the lecture. Both are required.
