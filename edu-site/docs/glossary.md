# Glossary

This page is generated from `curriculum-state/ledgers/concept-ledger.yaml` — specifically, from every entry whose `status` is `defined`. A term still marked `used-undefined` or `proposed` in that ledger is a known debt, not a settled definition, and does not appear here yet. If a later chapter reuses one of the words below, it reuses this exact wording — that consistency is the entire point of tracking terms in one place.

### Agent

A program that can read your files, write new code, edit existing code, and run commands on a computer — on its own, in a sequence, without asking you to approve every single step.

*First defined in [Spec-Driven Engineering](/intro-5-spec-driven-engineering), Beginner · Summary.* An everyday-language version of the same idea also appears in Beginner · Balanced: *a very fast, very capable helper — not an architect, and not the owner of the result.*

### Blast radius

How much can break, and how far the damage reaches, if a change goes wrong.

*First defined in [Spec-Driven Engineering](/intro-5-spec-driven-engineering), Advanced · Detailed (Surface 2 — Tool calling).*

### Specification (spec)

A written statement of what you want built and what shouldn't change, agreed before you start.

*First defined in [Spec-Driven Engineering](/intro-5-spec-driven-engineering), Beginner · Summary.*

### Spec-Driven Engineering

The discipline in which the engineer specifies intent and boundaries, the AI implements within them, and a human verifies before taking ownership.

*First defined in [Spec-Driven Engineering](/intro-5-spec-driven-engineering) (all cells — this is the book's thesis). Curriculum-coined; must be defined on first use in every cell that relies on it, including Advanced cells, because this is this project's own vocabulary rather than field-standard terminology.*

### Vibe coding

Building software entirely through iterative AI prompts without understanding the underlying code. Coined by Andrej Karpathy, February 2025; named Collins Dictionary's Word of the Year for 2025.

*First defined in [Spec-Driven Engineering](/intro-5-spec-driven-engineering), Beginner · Balanced. Always attributed — never presented as this curriculum's own coinage.*
