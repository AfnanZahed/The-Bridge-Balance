# Implementation Plan: Apple-Inspired Theme Transformation

**Branch**: `002-apple-design` | **Date**: 2026-08-17 | **Spec**: [./spec.md](./spec.md)
**Input**: Feature specification from `/specs/002-apple-design/spec.md`

## Summary

Transform the Docusaurus textbook's visual identity from its current saturated,
motion-heavy presentation to the **Apple-inspired visual language** ratified in
Constitution Principle VII (Apple-Design Purity), guided by the 5 clarifications
resolved for this feature:

1. Mute stage accents to Apple-grade (teal, ochre, lilac, dusty rose).
2. Adopt Apple-system blue as the single primary accent (links, focus, CTAs).
3. Strip heavy motion: remove Lenis smooth scroll, GSAP scroll-spine, and the
   R3F 3D hero; keep only Framer Motion entrance reveals (which collapse under
   reduced motion).
4. Keep the type stack (Inter / Instrument Serif / Geist Mono) but tune it
   Apple-style: bolder display weights, tighter tracking, generous reading
   leading; serif reserved for editorial moments.
5. Charts use a single accent + neutrals; stage identity via labels, not color
   alone.

This is a *presentation-layer* change. Curriculum routes, sidebar order,
chapter-state indicators, icon taxonomy, content contracts, and the free-tier
commitment are explicitly preserved (FR-012, FR-013, SC-006, SC-007).

## Technical Context

**Language/Version:** TypeScript 5.5.x; Node.js ≥ 18; Docusaurus 3.7.x (site is already green).
**Primary Dependencies:** React 18.x, MDX 3.x, `motion` (Framer Motion) entrance reveals, Recharts 3.x (retained), Open Props + Radix Colors (tokens).
**Removed Dependencies:** `lenis`, `gsap` (+ ScrollTrigger), `@react-three/fiber@8`, `@react-three/drei`, `@react-three/rapier`, `three` — runtime motion/3D layers stripped per PR-PL (FR-007/FR-011).
**Storage:** None in Phase A + — no schema change.
**Testing:** Smoke at `npm run build` + `npx tsc --noEmit`; design-fidelity review (FR-014) as the acceptance gate; automated Lighthouse/Axe audit already in CI.
**Target Platform:** Vercel free tier (unchanged).
**Project Type:** Web — Docusaurus static site (presentation layer only).
**Performance Goals:** Static hero reduces JS main-thread cost; maintain Lighthouse perf ≥ 90 and a11y ≥ 95 (SC-004/SC-005/SC-007).
**Constraints:** Free-tier only; no new paid runtime deps; no proprietary Apple assets/fonts; no IA/content/schema change.
**Scale/Scope:** Design tokens + surfaces across ~7 page types + motion removal. No new pages.

## Implementation Phases

### Phase 1 — Token & Type Foundation
- Re-map `radix.css` semantic tokens: stage accents → muted scales; `--tbb-accent` → Apple-system blue; add subtle/glass/focus tokens.
- Re-map typography tokens (R-004): bold display weights, tight tracking, generous leading; serif usage confined to editorial moments.
- Prune `openprops.css` to self-contained tokens actually used.

### Phase 2 — Surface & Component Migration
- Restyle homepage hero to static panel (Apple-blue CTA, generous whitespace, static gradient; remove WebGL canvas).
- Restyle stage cards, chapter-state pill, navbar, sidebar, callouts with muted accents + soft elevation + blur fallback (R-006).
- Restyle DataViz: single-accent + neutrals; labels not color (R-005).
- Harden `a11y.css`: focus rings, contrast, forced-colors.

### Phase 3 — Motion Removal & Dependency Pruning
- Remove `Lenis` init from `Root.tsx`; remove `ScrollFX`/`gsap`/`Hero3D`; replace hero with static panel.
- Remove `lenis`, `gsap`, `@react-three/*`, `three` from `package.json`; prune `docusaurus.config.ts` customCss.
- Verify `RevealOnScroll` honors `prefers-reduced-motion`.

### Phase 4 — Build, Fidelity Review, Audit
- Run `npm run build`, `npx tsc --noEmit`, `node scripts/check-frontmatter.mjs`.
- Execute the design-fidelity review (FR-014): light/dark, contrast, blur fallback, reduced motion, keyboard focus, responsive overflow, degraded WebGL/assets.
- Confirm Lighthouse perf ≥ 90 / a11y ≥ 95 (SC-004/SC-005) and no page overflow at 320/768/1440 (SC-003).
