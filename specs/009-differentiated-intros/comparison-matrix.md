# Comparison Matrix — Nine Distinct Intro Reading Paths

This matrix is the editorial gate per FR-012 and FR-013. Each row records one Reading Contract and the corresponding Intro Version. A row is publishable only when the Verdict is `unique` and no peer row duplicates the same primary lens, scenario, structure, or takeaway.

## Column legend

- **Cell id**: C1–C9 from `contracts/reading-contracts.md`.
- **Difficulty / Length**: existing reader-control dimensions.
- **Audience**: the primary reader profile this version serves.
- **Lens**: unique teaching method (assigned exactly once per the lens registry).
- **Scenario**: concrete real-world situation, drawn only from the canonical source list.
- **Decision value**: the behavior or decision this version improves.
- **Structure**: the reasoning form this version uses.
- **Evidence**: the canonical incident(s) this version cites.
- **Takeaway**: the explicit, single action the reader should take.
- **Verdict**: `unique` (publishable), `duplicate lens`, `duplicate scenario`, `duplicate structure`, `duplicate takeaway`, or `pending`.
- **Notes**: thesis-check, scenario-attribution, or rejection notes.

## Verdict rule

A row's Verdict is `unique` only when its primary lens, scenario, reasoning structure, and takeaway are not duplicated by any other row. If any duplicate verdict is assigned, the affected row returns to `pending` until the version is rewritten.
