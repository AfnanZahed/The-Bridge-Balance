## Prompt

## Response snapshot

Started `npm start` from `edu-site/` in the background with `NODE_ENV=development` pinned (`set "NODE_ENV=development" && npm start -- --no-open`) — the pin is the lesson from PHR 0060, because this agent shell carries `NODE_ENV=production` in its process scope and that would otherwise make the dev server 404 doc routes. `--no-open` keeps the dev server from launching the OS default browser; Edge was then opened explicitly at `http://localhost:3000`, per the owner's standing preference.

The dev server compiles on first request, so the first probe caught an empty app shell and one transient `Cannot GET` on the chapter route; both routes returned HTTP 200 once the compile settled. Note that `docusaurus start` renders client-side, so a curl of `/` legitimately shows only `<div id="__docusaurus"></div>` — the search surfaces appear in the browser, not in the server HTML (the production build is the SSR one).

Left running (task `s1cjyd9d`) for the owner's preview — dark mode, mobile width, and the Spotlight's blob/spring feel are visual calls only the owner can make. Stop it with `kill_shell({ taskId: "s1cjyd9d" })` or Ctrl+C in the task's console when the preview is over.
